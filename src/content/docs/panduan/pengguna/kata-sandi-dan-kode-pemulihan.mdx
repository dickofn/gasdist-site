Karyawan lupa password atau akunnya terkunci? Reset password-nya dari halaman **User**. Ia mendapat password sementara dan wajib membuat password baru saat login.

<Roles can={["OWNER", "ADMIN"]} />

## Me-reset password karyawan

<Steps>

1. Buka **User** di menu samping, lalu klik **Reset password** <span class="pin">1</span> di baris orang itu.

   <Shot name="users-list" alt="Halaman User dengan tombol Reset password di setiap baris" marks={[null, null, 1]} />

2. Jendela **Reset password** menyebut username dan nama lengkap orang itu. Isi **Password sementara** <span class="pin">1</span>, minimal 8 karakter, dan ketik sekali lagi di **Ulangi password**.

   <Shot name="users-reset" alt="Jendela Reset password bambang dengan password sementara terisi" />

3. Klik **Simpan**. Baris orang itu kini bertanda **Wajib ganti password**.

4. Kasih password sementara itu ke orangnya. Saat login berikutnya, GasDist langsung memintanya membuat password baru. Caranya dijelaskan di [Login, kunci layar, dan password](/gasdist-site/panduan/mulai/masuk-dan-kunci/).

</Steps>

Begitu password di-reset, akun yang **Terkunci** karena salah password 5 kali juga langsung terbuka, jadi orang itu tidak perlu menunggu 5 menit.

| Situasi | Yang dilakukan |
|---|---|
| Karyawan (Gudang, Penjualan, Viewer) lupa password | Owner atau Admin me-reset password-nya, seperti di atas |
| Admin lupa password | Owner me-reset password-nya |
| Anda ingin mengganti password sendiri | Pakai **Ganti password** di bagian atas layar. Tombol **Reset password** tidak muncul di baris akun Anda sendiri |
| Owner lupa password | Owner lain bisa me-reset password-nya. Kalau tidak ada, pakai kode pemulihan di layar login (lihat [Login, kunci layar, dan password](/gasdist-site/panduan/mulai/masuk-dan-kunci/)) |

## Membuat kode pemulihan baru

<Roles can={["OWNER"]} />

Kode pemulihan dipakai untuk me-reset password Owner yang lupa. Kode itu ditampilkan sekali saat GasDist pertama kali di-setup. Di bawah tabel user, Owner melihat kotak **Kode pemulihan Owner** dengan tombol **Buat kode baru**.

Buat kode baru kalau:

- kertas berisi kode pemulihan hilang, atau
- kode itu mungkin sudah diketahui orang lain.

<Steps>

1. Klik **Buat kode baru** di kotak **Kode pemulihan Owner**.

2. Isi **Password** dengan password Anda sendiri, lalu klik **Buat kode baru**.

   <Shot name="users-recovery-new" alt="Jendela Buat kode baru yang meminta password Owner" />

3. Kode baru tampil di kotak berwarna. Tulis kode itu di kertas, persis seperti yang tampil.

4. Centang **Saya sudah mencatat kode ini**, lalu klik **Lanjut**. Tombol **Lanjut** baru bisa diklik setelah kotak itu dicentang.

</Steps>

<Aside type="caution" title="Kode lama langsung tidak berlaku">
Begitu kode baru dibuat, kode yang lama tidak bisa dipakai lagi. Kode baru hanya ditampilkan sekali dan GasDist tidak bisa menampilkannya lagi. Simpan kertasnya di tempat yang aman, terpisah dari PC.
</Aside>

Setelah kode pemulihan dipakai di layar login, GasDist otomatis memberi kode baru. Catat juga kode yang baru itu.
