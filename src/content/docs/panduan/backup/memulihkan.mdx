Restore berarti **mengganti semua data GasDist sekarang** dengan isi sebuah backup. Lakukan ini kalau data rusak atau terhapus, kalau Anda pindah ke PC lain, atau kalau Anda benar-benar perlu kembali ke keadaan pada tanggal backup itu.

<Roles can={["OWNER"]} />

## Apa yang terjadi saat restore

| Hal | Sesudah restore |
|---|---|
| Semua data: stok, surat jalan, pelanggan, data master, pengaturan | Persis seperti saat backup dibuat. Semua yang dicatat sesudah tanggal backup tidak ada lagi di data yang dipakai |
| Data sebelum restore | Disimpan dulu sebagai backup jenis **sebelum restore**, jadi masih bisa dikembalikan |
| User dan password login | Akun yang ada di backup. Semua orang login lagi dengan akun dan password dari backup |
| Password backup | Yang tersimpan di data backup itu, yaitu password yang Anda ketik untuk membukanya |
| Backup dari GasDist versi lebih lama | Di-update otomatis, Anda tidak perlu melakukan apa pun |
| Ukuran backup | Tidak ada batas. Dengan riwayat bertahun-tahun, **Periksa** dan **Restore** masing-masing bisa butuh beberapa menit; biarkan sampai selesai |
| Scan lembar kembali | Scan di folder `scans` di sebelah file backup yang dipilih disalin ke PC ini; scan yang sudah ada tidak disalin lagi. Lihat [Scan lembar kembali](/gasdist-site/panduan/backup/membuat-backup/#scan-lembar-kembali). |

## Me-restore sebuah backup

<Steps>

1. Buka **Pengaturan**, scroll ke paling bawah, lalu klik **Restore dari backup...** <span class="pin">1</span> di kotak **Backup dan restore**.

   <Shot name="settings-backup" alt="Kotak Backup dan restore dengan tombol Restore dari backup" marks={[null, null, null, 1]} />

2. Jendela **Restore dari backup** menampilkan **Backup yang ditemukan** di folder utama dan folder kedua, yang terbaru di atas. Setiap baris berisi tanggal dan jam, jenis backup (**otomatis**, **manual**, atau **sebelum restore**), ukurannya, dan tulisan **folder kedua** kalau berasal dari folder kedua. Pilih satu.

   Backup ada di flashdisk atau di tempat lain? Klik **Pilih file lain...**, lalu pilih file `.gasbak` di jendela pemilih file.

3. Isi **Password backup**, yaitu password backup yang berlaku **saat backup itu dibuat**, lalu klik **Periksa**. Langkah ini hanya membuka dan memeriksa backup; belum ada data yang diganti.

4. GasDist menampilkan isi backup: **Perusahaan**, **Dibuat** (tanggal dan jam, oleh siapa atau **otomatis**), dan **Versi**. Pastikan ini backup yang benar. Kalau salah pilih, klik **Kembali**.

5. Baca peringatan berwarna kuning: semua data sekarang akan diganti, backup data sekarang dibuat dulu, dan semua user login lagi dengan akun yang ada di backup.

6. Isi **Password Anda**, yaitu password yang Anda pakai untuk login ke GasDist, lalu klik **Restore**.

7. GasDist membuat backup data sekarang, mengganti datanya, lalu kembali ke layar login. Login dengan akun yang ada di backup itu.

</Steps>

<Aside type="caution" title="Tanpa password backup, backup tidak bisa dibuka">
Backup hanya bisa dibuka dengan password backup yang dipakai saat backup itu dibuat. Kalau password itu hilang, backup tersebut **tidak bisa di-restore sama sekali**, oleh siapa pun. Kode pemulihan Owner dan password login tidak bisa menggantikannya. Lihat [Password backup](/gasdist-site/panduan/backup/kata-sandi-backup/).
</Aside>

<Aside type="tip" title="Pindah ke PC baru">
Salin file `.gasbak` **bersama** folder `scans` di sebelahnya ke flashdisk, lalu pilih file itu di PC baru. Kalau folder `scans` tertinggal, data tetap kembali lengkap; cuma **Lihat scan** yang nanti bilang scan-nya tidak ada di PC ini. Salin folder itu belakangan ke folder backup, lalu restore lagi, atau salin isinya ke folder `scans` di folder data GasDist.
</Aside>

## Kalau ada pesan kesalahan

| Pesan | Artinya | Yang dilakukan |
|---|---|---|
| **Password backup salah, atau file backup telah berubah.** | Password tidak cocok dengan backup ini, atau file-nya rusak | Coba password backup yang berlaku saat backup dibuat (mungkin password lama). Kalau tetap gagal, pilih backup lain |
| **File ini bukan backup GasDist, atau file backup rusak.** | File yang dipilih bukan backup, atau rusak saat disalin | Pilih file lain, atau salin ulang dari flashdisk |
| **Backup ini dibuat oleh GasDist yang lebih baru. Update aplikasi dulu, lalu restore.** | Backup berasal dari GasDist versi lebih baru, misalnya backup dari GasDist 0.15.0 yang dipilih di GasDist 0.14.0. Untuk backup seperti itu yang lebih besar dari 1 GB, GasDist 0.14.0 menampilkan pesan **File ini bukan backup GasDist, atau file backup rusak.** | Install versi GasDist terbaru, lalu ulangi |
| **Password Anda salah.** | Password login di langkah 6 salah | Ketik ulang password Anda. Ini bukan password backup |

Semua pesan ini muncul **sebelum** data diganti. Data Anda sekarang tetap utuh.

## Membatalkan restore

Salah restore backup? Data sebelum restore tersimpan sebagai backup jenis **sebelum restore**. Ulangi langkah di atas dan pilih backup itu. Backup itu dikunci dengan password backup yang berlaku di PC ini sebelum restore. Kalau PC ini belum punya password backup, backup itu dikunci dengan password backup yang Anda ketik saat restore.

## Restore di PC baru

Pada PC baru yang belum di-setup, layar setup awal menawarkan **Pindah dari PC lain? Restore backup-nya, tanpa mengisi form ini.** Pilih file backup dari flashdisk, isi password backup, lalu restore. Di PC baru, GasDist tidak menanyakan password login karena belum ada data yang diganti. Setelah itu login dengan akun yang ada di backup. Lihat juga [Instalasi dan setup awal](/gasdist-site/panduan/mulai/penyiapan-awal/).
