Setiap backup GasDist dikunci (dienkripsi) dengan password backup. Dengan begitu, orang yang menemukan flashdisk berisi backup Anda tidak bisa membaca datanya. Password yang sama diperlukan untuk me-restore backup itu di PC mana pun.

<Roles can={["OWNER"]} />

<Aside type="caution" title="Atur password backup lebih dulu">
Selama password backup belum diatur, GasDist **tidak membuat backup apa pun**, baik otomatis maupun manual. Kotak **Backup** di halaman **Beranda** berwarna merah dan menulis **Backup belum aktif: belum ada password backup.**
</Aside>

## Mengatur password backup pertama kali

<Steps>

1. Klik **Atur password backup**. Tombol ini ada di kotak **Backup** di halaman **Beranda** (layar pertama setelah login), dan juga di kotak **Backup dan restore** di tab **Data** pada halaman **Pengaturan**.

2. Baca penjelasan di jendela **Password backup**, lalu isi **Password backup** dan ketik sekali lagi di **Ulangi password**. Minimal 8 karakter.

3. Klik **Simpan**. Muncul pesan **Password backup disimpan. Backup otomatis kini aktif.**

4. Tulis password itu di kertas dan simpan di tempat yang aman, misalnya bersama dokumen penting perusahaan.

</Steps>

Sejak saat itu GasDist membuat backup otomatis. User selain Owner yang melihat kotak merah tadi hanya mendapat pesan **Minta Owner mengatur password backup.**

## Mengganti password backup

<Steps>

1. Buka **Pengaturan**, klik tab **Data**, lalu klik **Ganti password backup** <span class="pin">1</span> di kotak **Backup dan restore**.

   <Shot name="settings-backup" alt="Kotak Backup dan restore dengan empat tombol" marks={[1, null, null, null]} />

2. Jendela **Password backup** terbuka. Kalimat tebal di tengahnya mengingatkan bahwa backup lama tetap memakai password lamanya.

   <Shot name="backup-password" alt="Jendela Password backup dengan penjelasan dan dua kolom password" />

3. Isi **Password backup** yang baru, ketik lagi di **Ulangi password**, lalu klik **Simpan**.

</Steps>

Password baru hanya berlaku untuk backup yang dibuat sesudahnya:

| Backup | Dibuka dengan |
|---|---|
| Dibuat sebelum password diganti | Password backup yang **lama** |
| Dibuat sesudah password diganti | Password backup yang **baru** |

Jadi jangan buang catatan password lama selama backup lama masih Anda simpan, misalnya di flashdisk.

## Password backup bukan password login

| Jenis | Untuk apa | Siapa yang punya |
|---|---|---|
| Password login | Login ke GasDist dan membuka layar terkunci | Setiap user punya sendiri |
| Kode pemulihan | Me-reset password Owner yang lupa | Owner |
| **Password backup** | Mengunci dan membuka file backup | Satu untuk seluruh kantor, diatur Owner |

Kode pemulihan **tidak bisa** membuka backup, dan password backup tidak bisa ditampilkan lagi oleh GasDist.

<Aside type="caution" title="Password backup hilang berarti backup tidak bisa dibuka">
Tidak ada cara untuk membuka backup tanpa password-nya, juga tidak oleh pembuat GasDist. Kalau password backup hilang, semua backup yang dikunci dengan password itu tidak bisa dibuka lagi. Simpan catatannya terpisah dari flashdisk backup, dan pastikan lebih dari satu orang yang dipercaya tahu tempatnya.
</Aside>
