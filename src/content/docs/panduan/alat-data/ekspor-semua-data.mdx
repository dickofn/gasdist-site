Export semua data menyalin setiap tabel GasDist ke satu file Excel (xlsx): pelanggan, produk, kendaraan, sopir, surat jalan dan barisnya, penerimaan stok, kartu stok, riwayat perubahan, user, dan pengaturan. Gunanya untuk akuntan, arsip di luar GasDist, atau memindahkan data ke program lain.

<Roles can={["OWNER"]} />

Hanya Owner, karena file ini **tidak terenkripsi**: siapa pun yang memegangnya bisa membaca semua data, termasuk NIK dan nomor telepon pelanggan. Untuk menjaga data dari kerusakan atau kehilangan, pakai [backup](/gasdist-site/panduan/backup/membuat-backup/), yang terenkripsi dan bisa di-restore. File export tidak bisa di-restore ke GasDist.

## Meng-export

<Steps>

1. Klik **Pengaturan** di menu samping, buka tab **Data**, lalu cari kotak **Export semua data** di bawah backup.

2. Klik **Export ke Excel...** <span class="pin">1</span>, lalu pilih tempat menyimpan file di dialog simpan. Nama yang diusulkan berisi tanggal hari ini, misalnya `GasDist-semua-data-2026-10-13.xlsx`.

3. Export berjalan di latar belakang. Selama itu, kotaknya menyebut tabel yang sedang ditulis dan berapa baris yang sudah selesai, lalu **Menyimpan file xlsx...** di akhir. GasDist tetap bisa dipakai seperti biasa; **Hentikan** membatalkan export tanpa menyimpan file.

4. Setelah selesai, pesan <span class="pin">2</span> menyebut letak file, jumlah baris, dan lamanya.

   <Shot name="settings-export" alt="Kotak Export semua data setelah selesai, dengan pesan letak file dan jumlah baris" />

</Steps>

Sebelum mulai, GasDist memeriksa tempat simpannya. Kalau file dengan nama yang sama sedang terbuka, misalnya di Excel, tutup dulu atau pilih nama lain. Folder data GasDist sendiri tidak bisa dipakai.

Data yang sudah bertahun-tahun butuh waktu: dengan riwayat sepuluh tahun (sekitar 470.000 surat jalan), export memakan sekitar satu menit dan file-nya sekitar 400 MB. Selama export, GasDist memakai ruang kosong di disk kira-kira dua kali ukuran database-nya untuk sementara.

## Isi file

| Sheet | Isinya |
|---|---|
| **Info** | Perusahaan, waktu export, siapa yang meng-export, versi aplikasi, jumlah baris setiap tabel dan sheet-nya, serta apa saja yang tidak ikut dan alasannya |
| Satu sheet per tabel | Baris pertama berisi nama kolom seperti di database, lalu satu baris per data |

Sejak versi 0.13.0 ada juga sheet `customer_returns` dan `customer_return_lines` ([retur](/gasdist-site/panduan/surat-jalan/retur/) dan barisnya), `cylinder_movements` (setiap perubahan tabung dipinjam) dan `cylinder_balance` (saldonya per pelanggan, produk, dan sumber).

Isinya ditulis apa adanya seperti di database: berat dalam **gram** (bukan kg), tanggal sebagai `2026-10-13`, dan waktu dalam UTC. Tabel yang lebih panjang dari satu sheet Excel (1.048.575 baris) berlanjut di sheet berikutnya, misalnya `audit_log (2)`.

## Yang tidak ikut

| Yang tidak ikut | Alasan |
|---|---|
| Password user, kode pemulihan, password backup, dan kunci scan | Rahasia: bisa dipakai untuk login atau membuka backup dan scan |
| Riwayat login (sesi) | Hanya dipakai untuk aturan penguncian layar |
| Logo perusahaan | Gambar, bukan data yang bisa ditampilkan sheet |
| Kunci database | Tidak pernah ada di dalam database; tersimpan di sistem operasi |
| Scan lembar kembali | Tetap berupa file terenkripsi di folder `scans` di sebelah database dan ikut di setiap backup. Sheet `attachments` mendaftar setiap scan; buka scan dari surat jalannya |

<Aside type="note">
Setiap export yang selesai tercatat di [riwayat perubahan](/gasdist-site/panduan/laporan/jejak-audit/) sebagai **Semua data di-export**, dengan nama file dan jumlah baris per tabel. Export yang dihentikan atau gagal tidak meninggalkan file dan tidak tercatat.
</Aside>
