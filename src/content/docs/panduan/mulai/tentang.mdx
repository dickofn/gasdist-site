GasDist mencatat stok LPG dalam kg dan surat jalan dalam tabung untuk distributor. Aplikasi ini bekerja sepenuhnya **offline** di satu PC: tidak butuh internet, dan semua data tersimpan di PC itu dalam keadaan **terenkripsi**. Halaman ini mengenalkan jendela utama supaya Anda tahu di mana mencari setiap fitur.

<Roles can={["OWNER", "ADMIN", "GUDANG", "PENJUALAN", "VIEWER"]} />

## Jendela utama

Setelah masuk, GasDist selalu membuka halaman **Stok**. Jendela utama terdiri dari menu samping di kiri dan baris atas di kanan.

<Shot name="home" alt="Jendela utama GasDist: menu samping di kiri, nama perusahaan dan tombol akun di atas, kartu stok per produk di tengah" />

| Bagian | Gunanya |
|---|---|
| Menu samping <span class="pin">1</span> | Pindah antarhalaman. Menu yang tampil tergantung [peran](/gasdist-site/panduan/mulai/peran/) Anda. Nomor versi GasDist ada di bawahnya. |
| Nama perusahaan | Di kiri baris atas, misalnya **PT Sumber Gas Sejahtera**. Owner mengubahnya di [Pengaturan](/gasdist-site/panduan/pengaturan/perusahaan/). |
| **Bahasa** <span class="pin">2</span> | Pilih **Bahasa Indonesia** atau **English**. Pilihan ini disimpan untuk akun Anda sendiri, jadi pengguna lain tidak terpengaruh. |
| Nama dan peran | Siapa yang sedang masuk, misalnya **Hendra Wijaya · Owner**. |
| **Ganti kata sandi** | Mengganti kata sandi Anda sendiri. Lihat [Masuk, kunci layar, dan kata sandi](/gasdist-site/panduan/mulai/masuk-dan-kunci/). |
| **Kunci** <span class="pin">3</span> | Mengunci layar saat Anda meninggalkan meja. Anda tetap masuk; membukanya cukup dengan kata sandi. |
| **Keluar** | Mengakhiri sesi Anda, lalu kembali ke layar masuk. |

Di halaman Stok sendiri ada tombol seperti **Terima stok** <span class="pin">4</span>, kartu backup, dan satu kartu per produk. Label **Menipis** <span class="pin">5</span> menandai produk yang stoknya di bawah batas. Penjelasan lengkapnya ada di [Ringkasan stok](/gasdist-site/panduan/stok/ringkasan/).

## Isi menu samping

| Menu | Untuk apa | Panduan |
|---|---|---|
| **Stok** | Halaman awal: stok tiap produk dalam kg dan tabung, status backup, terima stok, stok opname | [Ringkasan stok](/gasdist-site/panduan/stok/ringkasan/) |
| **Surat Jalan** | Daftar surat jalan, membuat, memposting, mencetak, membatalkan | [Daftar dan ekspor surat jalan](/gasdist-site/panduan/surat-jalan/daftar/) |
| **Pelanggan** | Data pangkalan dan pelanggan lain, pencarian, riwayat surat jalan per pelanggan | [Daftar dan pencarian pelanggan](/gasdist-site/panduan/pelanggan/daftar/) |
| **Master Data** | Produk, kendaraan, dan sopir | [Produk](/gasdist-site/panduan/data-master/produk/) |
| **Laporan** | Kartu stok per produk, bisa diekspor ke Excel atau CSV | [Kartu stok](/gasdist-site/panduan/stok/kartu-stok/) |
| **Pengguna** | Menambah akun, mengatur ulang kata sandi | [Menambah pengguna](/gasdist-site/panduan/pengguna/menambah/) |
| **Pengaturan** | Data perusahaan, format nomor, stok minus, kunci otomatis, bahasa, backup | [Perusahaan dan logo](/gasdist-site/panduan/pengaturan/perusahaan/) |

<Aside type="note">
Tidak melihat salah satu menu di atas? Itu wajar: menu disembunyikan bila peran Anda tidak berhak memakainya. Lihat [Peran pengguna](/gasdist-site/panduan/mulai/peran/).
</Aside>

## Tampilan terang dan gelap

GasDist mengikuti tema sistem operasi. Bila Windows (atau Linux) Anda memakai mode gelap, GasDist ikut gelap; isinya sama persis, hanya warnanya yang berubah. Tidak ada pengaturan tema terpisah di dalam GasDist.
