Setup awal hanya dilakukan sekali per PC: meng-install aplikasi, mengisi data perusahaan, dan membuat akun Owner pertama. Orang yang melakukan setup GasDist otomatis menjadi **Owner**, role yang punya semua akses.

## Install GasDist

Installer diberikan sebagai satu file, misalnya lewat flashdisk. Instalasi tidak butuh internet dan tidak perlu meng-install database atau program lain.

| Sistem | File | Cara install |
|---|---|---|
| Windows 10 (21H2 atau lebih baru) atau Windows 11, 64-bit | `GasDist_<versi>_x64-setup.exe` | Klik dua kali file-nya, lalu ikuti langkah di layar. Semua yang dibutuhkan sudah ada di dalam installer. |
| Linux (Ubuntu 22.04+ atau Debian 12+) | `GasDist_<versi>_amd64.deb` | Buka dengan installer paket default sistem. |
| Linux, tanpa install | `GasDist_<versi>_amd64.AppImage` | Izinkan file dijalankan sebagai program, lalu klik dua kali. |

Di Windows, installer lebih dulu menampilkan **perjanjian lisensi** GasDist, dalam Bahasa Indonesia dan English. Klik **I Agree** untuk melanjutkan. Singkatnya: satu lisensi berlaku untuk satu badan usaha, di PC sebanyak apa pun milik badan usaha itu, tanpa batas waktu. Induk, anak, dan saudara perusahaan membutuhkan lisensi sendiri, dan installer tidak boleh dibagikan ke luar perusahaan. Update lewat **Update dari file...** tidak menampilkan perjanjian ini lagi.

Setelah terinstall, buka **GasDist** dari menu Start (atau menu aplikasi di Linux). GasDist mulai dengan masa trial 7 hari; setelah setup awal di bawah, tambahkan file lisensi dari penjual GasDist. Lihat [Lisensi dan masa trial](/gasdist-site/panduan/mulai/lisensi/).

<Aside type="note" title="Peringatan Windows saat install">
Installer GasDist tidak ditandatangani secara digital (code signing). Kalau installer di-download dengan browser, Windows menampilkan **Windows protected your PC** (SmartScreen): klik **More info**, lalu **Run anyway**, dan instalasi berjalan seperti biasa. Installer yang disalin dari flashdisk biasanya langsung berjalan tanpa peringatan ini.
</Aside>

<Aside type="caution" title="Matikan Smart App Control di Windows 11">
**Smart App Control** memblokir aplikasi yang tidak ditandatangani tanpa tombol untuk melanjutkan, jadi GasDist tidak bisa di-install selama fitur ini menyala. Sebelum install, buka **Windows Security › App & browser control › Smart App Control settings** dan pilih **Off**. Di banyak PC Windows 11, Smart App Control tidak bisa dinyalakan lagi setelah dimatikan.
</Aside>

Simpan file AppImage di satu tempat tetap, misalnya folder `AppImages` di folder pribadi Anda: update menggantinya di tempat itu. Versi berikutnya di-install dari dalam GasDist dengan satu file update; lihat [Update GasDist](/gasdist-site/panduan/mulai/memperbarui/).

## Mengisi data perusahaan dan akun Owner

Saat dibuka pertama kali, GasDist menampilkan layar **Selamat datang di GasDist**. Pilih dulu bahasanya di **Bahasa** kanan atas kalau perlu.

<Shot name="setup-empty" alt="Layar Selamat datang di GasDist dengan form perusahaan dan akun Owner yang masih kosong" />

<Steps>

1. Di bagian **Perusahaan**, isi **Nama perusahaan** <span class="pin">1</span>. **Telepon**, **Alamat**, dan **NPWP** boleh diisi sekarang atau nanti di [Pengaturan](/gasdist-site/panduan/pengaturan/perusahaan/). Data ini tercetak di kepala surat jalan. Begitu lisensi ditambahkan, nama perusahaan dan NPWP mengikuti lisensi.

2. Di bagian **Akun Owner**, isi **Nama lengkap**, **Username** <span class="pin">2</span>, **Password**, dan **Ulangi password**.

   - Username: 3 sampai 32 huruf, angka, titik, garis bawah (_) atau strip (-), tanpa spasi.
   - Password: minimal 8 karakter.

   <Shot name="setup-filled" alt="Form setup yang sudah terisi untuk PT Sumber Gas Sejahtera dengan Owner Hendra Wijaya" />

3. Periksa sekali lagi, lalu klik **Selesai dan login** <span class="pin">3</span>.

</Steps>

<Aside type="tip" title="Pindah dari PC lain?">
Jangan isi form ini. Klik **Restore dari backup...** di bawah form dan pilih file backup dari PC lama. Setelah itu login dengan akun yang ada di backup. Lihat [Restore dari backup](/gasdist-site/panduan/backup/memulihkan/).
</Aside>

## Menyimpan kode pemulihan

Setelah form dikirim, GasDist menampilkan **kode pemulihan** satu kali saja. Kode ini satu-satunya cara untuk reset password Owner kalau lupa.

<Shot name="setup-recovery-code" alt="Layar Simpan kode pemulihan dengan kode pemulihan, kotak centang Saya sudah mencatat kode ini, dan tombol Lanjut" />

<Steps>

1. Baca penjelasannya <span class="pin">1</span>, lalu **tulis kode di kotak kuning di atas kertas**. Kode terdiri dari empat kelompok berisi lima huruf atau angka.

2. Simpan kertas itu di tempat yang aman, jauh dari PC. Jangan simpan di file di PC yang sama: kalau PC rusak, kodenya ikut hilang.

3. Centang **Saya sudah mencatat kode ini** <span class="pin">2</span>. Tombol **Lanjut** <span class="pin">3</span> baru bisa diklik setelah kotak ini dicentang.

4. Klik **Lanjut**. Anda langsung login dan jendela utama terbuka.

</Steps>

<Aside type="caution" title="Kode ini tidak ditampilkan lagi">
Kalau Anda melewatkan langkah ini tanpa mencatat kodenya, tidak ada cara melihatnya kembali. Owner bisa membuat kode baru kapan saja dari menu **User** (kode lama langsung tidak berlaku). Lihat [Reset password dan kode pemulihan](/gasdist-site/panduan/pengguna/kata-sandi-dan-kode-pemulihan/).
</Aside>

Setiap kali kode dipakai untuk reset password, GasDist langsung memberi kode baru dengan layar yang sama. Catat kode baru itu juga.

## Mencoba data contoh

Selama database masih kosong, halaman **Beranda** menampilkan kartu **Coba GasDist dengan data contoh** <span class="pin">1</span>. Kartu ini hanya tampil untuk Owner.

<Shot name="home-empty-demo" alt="Halaman Beranda yang masih kosong dengan kartu Coba GasDist dengan data contoh, tombol Sembunyikan dan Isi data contoh" />

Ada dua pilihan, dan keduanya meminta konfirmasi dulu:

| Tombol | Hasilnya |
|---|---|
| **Isi data contoh** | GasDist mengisi produk, pelanggan, kendaraan, sopir, stok, dan beberapa surat jalan contoh. Hanya bisa sekali. |
| **Sembunyikan** | Kartu hilang dan tidak akan muncul lagi. |

<Aside type="caution" title="Data contoh tidak bisa dihapus satu per satu">
Data contoh tercatat permanen di riwayat stok, nomor surat jalan, dan riwayat perubahan. Data master contoh hanya bisa dinonaktifkan. Selesai berlatih, Owner bisa mengosongkan semuanya sekaligus dengan [Hapus semua data](/gasdist-site/panduan/pengaturan/hapus-semua-data/), lalu mulai dari setup awal. Untuk langsung dipakai sungguhan, klik **Sembunyikan**.
</Aside>

Pilihan ini hanya tersedia selama database masih kosong. Begitu Anda mengisi data sendiri, kartunya tidak muncul lagi.

## Langkah berikutnya

Kartu merah **Backup** di atasnya menandakan backup belum aktif. Atur password backup lebih dulu lewat **Atur password backup**, sebelum data sungguhan masuk. Lihat [Password backup](/gasdist-site/panduan/backup/kata-sandi-backup/). Setelah itu:

1. Tambahkan [file lisensi](/gasdist-site/panduan/mulai/lisensi/#menambah-lisensi) dari penjual GasDist, supaya masa trial tidak habis di tengah pekerjaan.
2. Isi [produk](/gasdist-site/panduan/data-master/produk/), lalu [kendaraan dan sopir](/gasdist-site/panduan/data-master/kendaraan-dan-sopir/).
3. Tambahkan [pelanggan](/gasdist-site/panduan/pelanggan/menambah/).
4. Buat akun untuk staf di [Menambah user](/gasdist-site/panduan/pengguna/menambah/).
5. Catat stok awal dengan [Menerima stok](/gasdist-site/panduan/stok/terima-stok/).
6. Di Windows, export satu file csv (misalnya [kartu stok](/gasdist-site/panduan/stok/kartu-stok/)) lalu buka di Excel. Kalau setiap baris tampil dalam satu kolom, ubah [Pemisah CSV](/gasdist-site/panduan/pengaturan/stok-dan-keamanan/#pemisah-csv) di **Pengaturan**.

## Mencopot GasDist

Di Windows, buka **Settings › Apps › Installed apps**, cari **GasDist**, lalu **Uninstall**. Data GasDist tetap tersimpan di folder `%APPDATA%\GasDist` (beserta kuncinya di Windows Credential Manager), juga kalau kotak **Delete the application data** dicentang. Kalau GasDist di-install lagi, datanya langsung terbuka seperti semula.

Data sengaja tidak ikut terhapus. Kalau PC akan diberikan ke orang lain atau data memang harus dihapus, [buat backup](/gasdist-site/panduan/backup/membuat-backup/) dan simpan di luar PC dulu, lalu hapus folder `%APPDATA%\GasDist` sendiri.
