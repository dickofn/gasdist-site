Pengaturan ini berlaku untuk semua user di kantor: apakah stok boleh minus, kapan layar terkunci sendiri, bahasa default, dan pemisah kolom file CSV. Semuanya ada di tab **Umum** pada halaman **Pengaturan**.

Setelah mengubah apa pun di tab ini, klik **Simpan** di bar yang muncul di bagian bawah layar. Muncul pesan **Pengaturan disimpan.**

## Stok minus

Di tab **Umum** ada kotak centang **Izinkan stok minus saat posting surat jalan** <span class="pin">1</span>. Default-nya tidak dicentang.

| Kotak centang | Kalau stok tidak cukup untuk sebuah surat jalan |
|---|---|
| Tidak dicentang (default) | Baris itu merah bertanda **Minus** dan tombol **Posting** tidak bisa diklik. Kurangi jumlahnya dulu. ✅ Disarankan |
| Dicentang | Baris itu tetap merah bertanda **Minus**, tapi surat jalan tetap bisa diposting. GasDist hanya memberi peringatan, lalu stok produk itu menjadi minus |

Lihat juga [Membuat surat jalan](/gasdist-site/panduan/surat-jalan/membuat/) untuk arti warna di kolom **Stok setelah**.

<Aside type="caution">
Stok minus berarti catatan di GasDist sudah tidak cocok dengan isi gudang. Biasanya penyebabnya penerimaan stok yang belum dicatat. Lebih baik [catat penerimaan stok](/gasdist-site/panduan/stok/terima-stok/) dulu, atau perbaiki dengan [stok opname](/gasdist-site/panduan/stok/stok-opname/), daripada mengizinkan stok minus.
</Aside>

## Kunci otomatis

Di bawah kotak centang stok minus ada kolom **Kunci otomatis setelah (menit)** <span class="pin">2</span>. Kalau GasDist tidak dipakai selama itu, layar terkunci sendiri dan user harus memasukkan password-nya untuk melanjutkan. Sebaiknya simpan dulu draft atau isian yang sedang dikerjakan sebelum meninggalkan PC. Cara membuka kunci dijelaskan di [Login, kunci layar, dan password](/gasdist-site/panduan/mulai/masuk-dan-kunci/).

| Kunci otomatis | Menit |
|---|---|
| Default | 15 |
| Yang boleh diisi | 1 sampai 240 |

<Aside type="tip">
PC di meja yang ramai dilewati orang sebaiknya memakai waktu pendek, misalnya 5 menit. Siapa pun juga bisa mengunci layar kapan saja dengan tombol **Kunci** di bagian atas layar.
</Aside>

## Bahasa default

Di tab **Umum**, pilih **Bahasa default** <span class="pin">3</span>: **Bahasa Indonesia** atau **English**.

| Tempat | Bahasa yang dipakai |
|---|---|
| Layar login | Bahasa default |
| User dengan bahasa **Ikuti default perusahaan** | Bahasa default |
| User yang memilih bahasanya sendiri | Bahasa pilihannya, apa pun bahasa default-nya |

Bahasa per user diatur di halaman **User** (lihat [Menambah user](/gasdist-site/panduan/pengguna/menambah/)), atau oleh user itu sendiri lewat pilihan **Bahasa** di bagian atas layar.

## Pemisah CSV

Di tab **Umum**, di bawah **Bahasa default**, ada **Pemisah CSV** <span class="pin">4</span>. Pilihan ini menentukan tanda pemisah kolom di setiap file csv yang di-export GasDist (daftar surat jalan, kartu stok, dan semua laporan). Tanda desimal angka kg ikut dengan pemisahnya.

| Pilihan | Pemisah kolom, tanda desimal | Cocok untuk |
|---|---|---|
| **Ikuti bahasa** (default) | Titik koma dan koma (`;` `,`) bagi user berbahasa Indonesia, koma dan titik (`,` `.`) bagi yang berbahasa Inggris | Kantor yang pengaturan wilayah Windows-nya sama dengan bahasa GasDist |
| **; (Excel Indonesia)** | `;` dan `,` untuk semua user | Windows dengan wilayah Indonesia |
| **, (Excel English)** | `,` dan `.` untuk semua user | Windows dengan wilayah berbahasa Inggris, misalnya English (Indonesia) atau English (United States) |

Excel memisahkan kolom file csv menurut pengaturan wilayah Windows (Settings › Time & language › Region), bukan menurut bahasa GasDist. Cara mengujinya: export satu file csv, misalnya kartu stok, lalu buka di Excel. Kalau setiap baris tampil dalam satu kolom, pilih pemisah yang lain di sini, simpan, lalu export lagi.

File Excel (**Export Excel**) tidak terpengaruh dan terbuka dengan benar di PC mana pun. [Import pelanggan](/gasdist-site/panduan/alat-data/impor-pelanggan/) juga tidak terpengaruh: GasDist mengenali sendiri pemisah file csv yang di-import.

## Folder backup kedua

Tab **Data** berisi **Folder backup kedua** (tombol **Pilih folder**) dan **Simpan berapa backup**. Keduanya dijelaskan di [Membuat dan menyalin backup](/gasdist-site/panduan/backup/membuat-backup/).
