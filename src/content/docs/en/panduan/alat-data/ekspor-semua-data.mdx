Export all data copies every GasDist table into one Excel (xlsx) file: customers, products, vehicles, drivers, surat jalan and their lines, stock receipts, the stock ledger, the audit trail, users and settings. It is for an accountant, an archive outside GasDist, or moving the data to another program.

<Roles can={["OWNER"]} />

Owner only, because the file is **not encrypted**: whoever holds it can read all the data, customers' NIK and phone numbers included. To keep data safe from damage or loss, use a [backup](/gasdist-site/en/panduan/backup/membuat-backup/), which is encrypted and can be restored. An export cannot be restored into GasDist.

## Exporting

<Steps>

1. Click **Settings** in the sidebar, then scroll to the **Export all data** box below the backups.

2. Click **Export to xlsx...** <span class="pin">1</span> and choose where to save the file in the save dialog. The suggested name carries today's date, for example `GasDist-all-data-2026-10-13.xlsx`.

3. The export runs in the background. Meanwhile the box names the table being written and how many rows are done, then **Saving the xlsx file...** at the end. GasDist stays usable as usual; **Stop** cancels the export without saving a file.

4. When it is done, the message <span class="pin">2</span> names the file, the number of rows and how long it took.

   <Shot name="settings-export" alt="The Export all data box when done, with the message naming the file and the number of rows" />

</Steps>

Before it starts, GasDist checks where the file goes. If a file of the same name is open, for example in Excel, close it first or choose another name. GasDist's own data folder cannot be used.

Years of data take time: with ten years of history (about 470,000 surat jalan) the export takes about a minute and the file is about 400 MB. While it runs, GasDist needs free disk space of about twice the size of its database for a short while.

## What the file holds

| Sheet | What it holds |
|---|---|
| **Info** | The company, when and by whom the export was made, the app version, the rows of each table and its sheets, and everything left out with the reason |
| One sheet per table | The first row holds the column names as in the database, then one row per record |

From version 0.13.0 there are also the sheets `customer_returns` and `customer_return_lines` ([returns](/gasdist-site/en/panduan/surat-jalan/retur/) and their lines), `cylinder_movements` (every change in the tabung on loan) and `cylinder_balance` (its balance per customer, product and source).

Values are written as the database holds them: weights in **grams** (not kg), dates as `2026-10-13`, and times in UTC. A table longer than one Excel sheet (1,048,575 rows) continues on the next sheet, for example `audit_log (2)`.

## What is left out

| Left out | Why |
|---|---|
| User passwords, recovery codes, the backup password and the scan key | Secrets: they would let someone sign in or open a backup or scan |
| Sign-in history (sessions) | Kept only for the screen lock rules |
| The company logo | A picture, not data a sheet can show |
| The database key | Never inside the database; the operating system keeps it |
| Signed-copy scans | They stay encrypted files in the `scans` folder beside the database and travel with every backup. The `attachments` sheet lists each scan; open a scan from its surat jalan |

<Aside type="note">
Every export that finishes is recorded in the [audit trail](/gasdist-site/en/panduan/laporan/jejak-audit/) as **All data exported**, with the file name and the rows per table. A stopped or failed export leaves no file and no record.
</Aside>
