These settings apply to every user in the office: whether stock may go negative, when the screen locks itself, the default language, and the column separator of CSV files. They are all on the **Settings** page, below the **Company**, **Documents** and **Surat jalan printing** sections.

After changing anything on this page, scroll to the very bottom and click **Save**. The message **Settings saved.** appears.

## Negative stock

<Shot name="settings-stock" alt="The Stock section with the Allow negative stock when posting a surat jalan checkbox" />

The **Stock** section has the checkbox **Allow negative stock when posting a surat jalan** <span class="pin">1</span>. It is unticked by default.

| Checkbox | When the stock is not enough for a surat jalan |
|---|---|
| Unticked (default) | The line turns red with **Negative** and the **Post** button is locked. Lower the quantity first. ✅ Recommended |
| Ticked | The line is still red with **Negative**, but the surat jalan can be posted. GasDist only warns, and that product's stock goes below zero |

See also [Making a surat jalan](/gasdist-site/en/panduan/surat-jalan/membuat/) for what the colours in the **Stock after** column mean.

<Aside type="caution">
Negative stock means the records in GasDist no longer match the warehouse. The usual cause is a stock receipt that was not recorded. It is better to [record the stock receipt](/gasdist-site/en/panduan/stok/terima-stok/) first, or correct it with a [stok opname](/gasdist-site/en/panduan/stok/stok-opname/), than to allow negative stock.
</Aside>

## Automatic lock

The **Security** section (to the right of the **Stock** section) has the field **Lock after (minutes)** <span class="pin">2</span>. When GasDist is not used for that long, the screen locks itself and the user must enter their password to continue. Save any draft or form you are working on before leaving the computer. How to unlock is explained in [Signing in, locking and passwords](/gasdist-site/en/panduan/mulai/masuk-dan-kunci/).

| Automatic lock | Minutes |
|---|---|
| Default | 15 |
| Allowed | 1 to 240 |

<Aside type="tip">
A computer on a busy desk is better off with a short time, for example 5 minutes. Anyone can also lock the screen at any time with the **Lock** button at the top of the screen.
</Aside>

## Default language

In the **Language** section, choose the **Default language** <span class="pin">3</span>: **Bahasa Indonesia** or **English**.

| Where | Language used |
|---|---|
| The sign-in screen | The default language |
| Users whose language is **Company default** | The default language |
| Users who chose their own language | Their own choice, whatever the default is |

The language for each user is set on the **Users** page (see [Adding users](/gasdist-site/en/panduan/pengguna/menambah/)), or by the user themselves with the **Language** choice at the top of the screen.

## CSV separator

In the **Language** section, under **Default language**, is **CSV separator** <span class="pin">5</span>. It sets the mark between the columns of every csv file GasDist exports (the surat jalan list, the kartu stok and every report). The decimal mark of kg figures goes with it.

| Choice | Column separator, decimal mark | Suits |
|---|---|---|
| **Follow the language** (default) | Semicolon and comma (`;` `,`) for users working in Indonesian, comma and full stop (`,` `.`) for those working in English | An office whose Windows region matches GasDist's language |
| **; (Excel Indonesia)** | `;` and `,` for every user | Windows set to the Indonesian region |
| **, (Excel English)** | `,` and `.` for every user | Windows set to an English region, such as English (Indonesia) or English (United States) |

Excel splits a csv file by the Windows region setting (Settings › Time & language › Region), not by GasDist's language. To test it, export one csv file, such as the kartu stok, and open it in Excel. If each row shows in a single column, choose the other separator here, save, and export again.

xlsx files (**Export xlsx** or **Export Excel**) are not affected and open correctly on any PC. [Importing customers](/gasdist-site/en/panduan/alat-data/impor-pelanggan/) is not affected either: GasDist recognises the separator of an imported csv by itself.

## Second backup folder

The **Backup** section on the same page holds **Second backup folder** (its **Choose folder** button <span class="pin">4</span>) and **Backups to keep**. Both are explained in [Making and copying backups](/gasdist-site/en/panduan/backup/membuat-backup/).
